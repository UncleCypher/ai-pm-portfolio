# 马尔可夫网络实验室

一个面向概率图模型学习与教学的交互式 Web 实验平台。用户可以创建无向图、编辑节点关系、生成二元变量的联合概率分布，并观察规则更新前后的分布与条件依赖变化。

## 为什么做这个项目

马尔可夫网络中的势函数、联合概率分布和条件独立性较为抽象。该项目将理论推导转化为可操作、可比较的交互实验，帮助学习者理解：

- 图结构与联合概率分布之间的关系；
- 规则更新如何引起概率质量迁移；
- 分布更新如何改变变量间的条件依赖；
- 原始模型与更新后模型的差异。

## 核心功能

- 创建包含 2-10 个二元变量的无向图；
- 点击节点添加或删除边；
- 为节点和边生成正势函数并精确归一化；
- 展示所有变量赋值的联合概率分布；
- 冻结原图并配置 `IF A=x THEN B=y` 规则；
- 对比更新前后的概率及变化量；
- 根据条件独立性检验生成更新后的依赖图；
- 逐对展示边、独立性结论和最大条件偏差。

## 产品流程

1. 输入节点数并生成变量；
2. 点击两个节点添加或删除边；
3. 确认图结构并生成联合概率分布；
4. 开始实验，冻结原始图；
5. 配置并应用 IF/THEN 规则；
6. 查看更新后的分布、依赖图和独立性检验结果。

## 运行方式

项目不依赖构建工具或第三方包。

```bash
git clone <repository-url>
cd markov-network-lab
```

随后直接打开 `index.html`，或使用任意静态文件服务器：

```bash
python -m http.server 8000
```

浏览器访问 `http://localhost:8000`。
