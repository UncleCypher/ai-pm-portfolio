CASE 001

GitHub 头像
一键转换器

把“头像上传失败”从一个格式问题，变成一次无感的本地转换。

用户不需要理解 PNG、尺寸或压缩参数。选择图片、调整位置、下载即可；所有图像处理都在浏览器本地完成。

需求分析MVP 原型隐私优先指标设计
目标用户首次配置或更换 GitHub 头像的用户
核心任务不学习图片规则，也能得到可直接上传的头像
关键假设本地自动处理能同时降低操作成本与隐私顾虑
成功标准一次完成转换，导出文件满足格式与大小要求
OOctoAvatar / LIVE DEMO
在独立页面打开 ↗
问题证据

格式、尺寸和文件大小是一次性任务，却要求用户先学习规则。

MVP 取舍

不做账号系统，不上传云端；用浏览器能力换取信任与更短路径。

已验证

上传、调整、格式转换与合规导出链路已通过自动化功能测试。

待验证指标

任务完成率、平均完成时长、首次导出成功率和失败原因分布。

HOW I WORK / 工作方式

先确认值得做，
再把它做对。

AI 让实现变快，也让“做错东西”的成本更隐蔽。我的工作重心，是持续减少产品判断中的不确定性。

01 / FRAME

定义真正的问题

区分用户表达的需求与实际任务，写清目标用户、使用场景和成功标准。

02 / PROBE

用原型探测答案

把关键假设变成可交互原型，用最短路径验证价值、可用性与技术边界。

03 / LEARN

让证据推动迭代

结合行为数据与定性反馈，判断该继续、调整还是停止，沉淀可复用认知。
