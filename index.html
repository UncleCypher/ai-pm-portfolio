CASE 001

GitHub 头像
一键转换器

把“头像上传失败”从一个格式问题，变成一次无感的本地转换。

用户不需要理解 PNG、尺寸或压缩参数。选择图片、调整位置、下载即可；所有图像处理都在浏览器本地完成。

需求分析MVP 原型隐私优先指标设计
目标用户首次配置或更换 GitHub 头像的用户
核心任务不学习图片规则，也能得到可直接上传的头像
关键假设本地自动处理能同时降低操作成本与隐私顾虑
成功标准一次完成转换，导出文件满足格式与大小要求

问题证据

格式、尺寸和文件大小是一次性任务，却要求用户先学习规则。

MVP 取舍

已验证

待验证指标

CASE 002

马尔可夫网络
实验室

把抽象的概率图模型推导，变成可编辑、可比较的实验过程。

学习者可以直接创建无向图、观察联合概率分布，并用 IF / THEN 规则迁移概率质量，理解图结构、条件独立与分布更新之间的关系。

学习产品交互可视化规则实验精确计算
目标用户正在学习概率图模型、需要建立直觉的学生与初学者
核心任务通过一次可操作实验理解图结构与联合分布的对应关系
关键假设即时反馈和前后对比能降低公式推导带来的认知负担
成功标准用户能独立建图、应用规则，并解释依赖关系为何改变
MARKOV NETWORK LAB / LIVE DEMO
在独立页面打开 ↗
问题证据

势函数、归一化常数和条件独立通常分散在公式中，学习者难以看到它们如何共同变化。

MVP 取舍

聚焦 2–10 个二元变量；不引入账号、云端计算和复杂参数编辑，先验证交互教学价值。

已验证

建图、精确分布计算、规则迁移、依赖图更新和移动端布局均已完成运行验证。

待验证指标

实验完成率、概念前后测提升、规则应用错误率，以及从建图到正确解释的用时。

CASE 003

全球智能售后
客服 Agent

把“机器不太正常”这样的自然语言，转化为可追溯、可验证、可安全升级的售后诊断流程。

Agent 负责理解与解释，结构化知识、规则和业务系统负责事实与高风险决策。完整版本支持页面内配置 DeepSeek API、运行时热切换、本地降级、症状归一化、候选根因、单步排查、危险场景拦截和未知问题转人工。

个人概念验证项目，以 MOVA 智能清洁设备为公开案例背景；非 MOVA 委托，未使用其内部数据。

Agent 工作流DeepSeek 热切换安全治理FastAPI
目标用户全球消费者、一线客服与售后技术支持人员
核心任务从模糊描述中识别问题，并给出安全、可执行、可追溯的下一步
关键假设LLM 理解与受控规则协作，能提升诊断覆盖率而不牺牲安全性
成功标准危险问题零漏拦截，Top-3 根因命中率与一次解决率达到上线门槛

问题证据

传统 FAQ 依赖用户准确描述和预设问题；面对“发烫”“不好用”等开放表达，容易反复追问或错误匹配。

MVP 取舍

聚焦扫地机器人高频场景；不做退款、拒保、拆机指导和无边界自动执行。

已验证

完成中文交互、症状归一化、候选根因、危险拦截、未知问题分流及 FastAPI 诊断接口原型。

待生产验证

需客户知识库、型号与固件数据、历史工单、真实 IoT 接口和人工闭环结果评估准确率。

HOW I WORK / 工作方式

先确认值得做，
再把它做对。

AI 让实现变快，也让“做错东西”的成本更隐蔽。我的工作重心，是持续减少产品判断中的不确定性。

01 / FRAME

定义真正的问题

区分用户表达的需求与实际任务，写清目标用户、使用场景和成功标准。

02 / PROBE

用原型探测答案

把关键假设变成可交互原型，用最短路径验证价值、可用性与技术边界。

03 / LEARN

让证据推动迭代

结合行为数据与定性反馈，判断该继续、调整还是停止，沉淀可复用认知。
