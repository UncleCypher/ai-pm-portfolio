## 作品集关注方向

- 从真实用户任务出发定义产品问题
- 将关键假设转化为可交互原型
- 平衡用户价值、技术边界与商业目标
- 使用证据推动产品迭代
- 明确区分功能验证、用户价值验证与待验证指标
- 持续补充 LLM、RAG、Agent 和模型评估类项目

## 项目组织方式

每个项目都位于 `projects/` 下的独立文件夹中，并拥有自己的页面、代码和 README：

```text
projects/
└── octoavatar/
    ├── README.md
    ├── index.html
    ├── styles.css
    └── app.js
```

具体项目的背景、功能、使用方法和技术说明，请查看对应项目目录中的 README。
