## 作品集关注方向

- 从真实用户任务出发定义产品问题
- 将关键假设转化为可交互原型
- 平衡用户价值、技术边界与商业目标
- 使用证据推动产品迭代
- 明确区分功能验证、用户价值验证与待验证指标
- 持续补充 LLM、RAG、Agent 和模型评估类项目

## 项目组织方式

三个项目在作品集中采用相同层级：均拥有首页产品入口、完整案例说明、可交互原型和独立 README。

```text
projects/
├── octoavatar/
│   ├── README.md
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── markov-network-lab/
│   ├── README.md
│   ├── index.html
│   ├── styles.css
│   └── app.js
└── global-support-agent/
    ├── README.md
    ├── index.html
    ├── styles.css
    └── app.js
```

其中“全球智能售后客服 Agent”是个人概念验证项目，以 MOVA 智能清洁设备为公开案例背景，非 MOVA 委托，也未使用 MOVA 内部数据。

具体项目的背景、功能、使用方法和技术说明，请查看对应项目目录中的 README。
